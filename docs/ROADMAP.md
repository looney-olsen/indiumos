# Roadmap and known gaps

- ISO build, Calamares install and greetd login are untested end to end.
- Layer-shell and window tracking are only tested without a real compositor.
- Wayfire cannot move titlebar buttons to the left; labwc can. Blur on layer surfaces and the Wayfire blur setup need testing.
- labwc dark titlebars need a second theme and a reconfigure when the appearance changes.
- A custom greeter to replace agreety.
- Calamares branding; removing live autologin on installed systems.
- Own logo, wallpapers and icons (see `branding/`).
- Later components: file manager integration, widgets, app store front end, more settings pages.
